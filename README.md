## О проекте

В данной лабораторной работе реализованы 7 алгоритмов на основе базовых структур данных (Стек, Массив, Дерево, Хеш-таблица, Двусвязный список), которые были написаны в Лабораторной работе №1.

Проект реализован на двух языках программирования: **C++** (в папке `c++/`) и **Rust** (в папке `rust/`). В C++ упор сделан на классическое ООП и работу с памятью, в Rust на безопасность памяти и систему владения (ownership).

## Структура проекта

Проект разделен на две независимые части.

### 1. C++ (`/c++`)

* `include/` заголовочные файлы структур данных (стек, массив, список, хеш-таблица).
* `src/` реализации структур.
* `tasks/` исходные коды 7 заданий.
* `bin/` скомпилированные исполняемые файлы (создаются автоматически).
* `Makefile` сборка всех задач.

**Сборка (C++):**

```bash
cd c++
make          # Соберет все задачи в папку bin/
```

### 2. Rust (`/rust`)

* `src/` модули структур данных и библиотека.
* `bin/` исходные коды 7 заданий (каждый компилируется в отдельный бинарник).
* `Cargo.toml` конфигурация проекта.

**Сборка (Rust):**

```bash
cd rust
cargo build   # Соберет проект
```

## Реализованные задания

### Задание 1. Обратная польская запись (Стек)

**Задача:** вычислить значение выражения в ОПЗ.  
**Структура:** Стек (LIFO).

* Запуск (C++): `./bin/task1`
* Запуск (Rust): `cargo run --bin rpn`

### Задание 2. АТД Множество (Хеш-таблица)

**Задача:** реализовать добавление, удаление и поиск элемента за O(1).  
**Структура:** Хеш-таблица (метод цепочек).

* Запуск (C++): `./bin/task2 --file my_set.data --query 'SETADD myset apple'`
* Запуск (Rust): `cargo run --bin set_task -- --file my_set.data --query 'SETADD myset apple'`

### Задание 3. Черепахи (Множество)

**Задача:** определить максимальное количество правдивых черепах.  
**Структура:** Множество (на базе хеш-таблицы).

* Запуск (C++): `./bin/task3`
* Запуск (Rust): `cargo run --bin turtles`

### Задание 4. Гистограмма (Массив)

**Задача:** построить вертикальную гистограмму частоты символов в тексте.  
**Структура:** Динамический массив.

* Запуск (C++): `./bin/task4`
* Запуск (Rust): `cargo run --bin histogram`

### Задание 5. Алгоритм Хаффмана (Бинарное дерево)

**Задача:** сжать строку в бинарный код и восстановить ее обратно.  
**Структура:** Бинарное дерево (собственная реализация для задачи).

* Запуск (C++): `./bin/task5`
* Запуск (Rust): `cargo run --bin huffman`

### Задание 6.1. Бенчмарк хеш-таблиц

**Задача:** сравнить скорость вставки и поиска для метода цепочек и хеширования кукушки.  
**Структура:** Хеш-таблицы.

* Запуск (C++): `./bin/task6.1`
* Запуск (Rust): `cargo run --bin benchmark`

### Задание 6.2. Изоморфные строки (Хеш-таблица)

**Задача:** проверить, являются ли две строки изоморфными.  
**Структура:** Метод цепочек (с проверкой префиксов).

* Запуск (C++): `./bin/task6.2`
* Запуск (Rust): `cargo run --bin isomorphic`

### Задание 7. LFU-кэш (Двусвязный список + Хеш-таблица)

**Задача:** реализовать кэш с вытеснением реже всего используемых элементов (Least Frequently Used).  
**Структура:** Двусвязный список + Хеш-таблица.

* Запуск (C++): `./bin/task7`
* Запуск (Rust): `cargo run --bin lfu`
